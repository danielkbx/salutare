Support
Help without creating a new account.

If you need help with Salutare, please use the options below.

Report an issue on GitHub

Slack: Install the app to your workspace, then run /salutare in any channel. If the command is not available, the app may not be installed or may require admin approval.

API: You can verify the service status via GET /api/v1/healthz and retrieve the greeting via GET /api/v1/greeting.
