Privacy Policy
Minimal, privacy-friendly by design.

Salutare is designed to be a simple, mostly stateless service. It provides a daily greeting via a public API and optional Slack integration.

Website & API: Like any web service, standard technical data is processed to serve requests (e.g. IP address, request path, user agent) as part of normal HTTP operation.

Slack integration: When you run the slash command, Slack sends a request containing command context such as workspace and user identifiers required to respond.

Storage: Salutare does not intentionally store Slack message content. Any stored data is limited to operational needs (configuration and service logs). Logs are intended to be operational and may contain anonymous statistics.

Third parties: Slack’s services are provided by Slack Technologies, LLC. Please review Slack’s policies for details on their data processing.
